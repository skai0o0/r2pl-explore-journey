R2PL itch.io HTML5 embed package

This package embeds the existing Demo at https://play.skai0o0.id.vn/.
It does not upload the game's client assets to itch.io. The game client,
models, API traffic, and WebSocket traffic remain served by the Demo host.

Upload itch-html5-demo.zip as an HTML game and choose an embed size that
matches your page. Test the uploaded page in a normal browser and on mobile.
If itch.io or the browser blocks nested frames or third-party cookies, use
the “Mở bản Demo riêng” link or prepare a dedicated itch-origin API setup.

This package does not point to Production.
